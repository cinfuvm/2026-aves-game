= Casos: batalla
:toc: left
:description: Casos de aceptación del sistema de batalla PPTLS, HP, PP, daño, rendición, relevo y resultados.

== Preparación

* Usar el modo de depuración para los casos que requieren valores deterministas: `?debug=1`.
* Parámetros disponibles: `hpJugador`, `hpCpu`, `pp`, `dano`, `cpuMove`, `seed`.
* Registrar el equipo y el orden de selección antes de iniciar la batalla.
* Verificar la consola del navegador antes y después de cada caso.

== Notas de ejecución

* Para UAT-BAT-005, UAT-BAT-006, UAT-BAT-007 y UAT-BAT-008 se requiere que el modo de depuración permita fijar el movimiento del CPU. Si no está implementado, repetir los turnos hasta observar el escenario y registrar la evidencia.
* La clasificación *Muy efectivo* usa la condición estricta `dano > 50 %`; el valor exacto del 50 % es *Efectivo*.
* El daño se calcula sobre el HP máximo del rival, no sobre el HP actual.
* La rendición manual debe requerir confirmación; la rendición por PP no.
* El historial no debe bloquear la selección de movimientos en móvil.
