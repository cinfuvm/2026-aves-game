== Instrucciones

1. Copiar las tablas de este documento a la hoja de cálculo o al tablero del equipo.
2. Registrar un resultado por caso: Aprobado, Fallido, Bloqueado o No aplica.
3. Adjuntar la evidencia con el formato `UAT-<ID>_<fecha>_<resultado>.<ext>`.
4. Si el caso falla, crear un defecto y referenciar su ID.
5. Actualizar la xref:uat:matriz-trazabilidad.adoc[matriz de trazabilidad].
6. Completar el resumen de métricas y el acta al final.
