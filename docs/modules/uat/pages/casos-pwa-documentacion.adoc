== Notas de ejecución

* Las pruebas de instalación PWA requieren HTTPS y un navegador compatible; GitHub Pages cumple con HTTPS.
* En iOS, la instalación se realiza desde *Compartir → Añadir a pantalla de inicio*; no siempre aparece un aviso automático.
* Limpiar la caché y desregistrar el service worker antes de probar una versión nueva.
* Las pruebas de Lighthouse deben ejecutarse en modo incógnito y sin extensiones.
* Registrar la URL y el tag evaluado en la evidencia.
